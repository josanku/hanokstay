# 한국관광공사(KTO) 협력 전략

## 결론 (1줄)

**KTO와 협의는 한다. 단 "을"로 들어가지 않고, 위홈이 작은 트랙션을 먼저 만든 뒤 협력 파트너로 진입한다.**

## 협력 시 잠재적 리스크

| 리스크 | 완화 |
|--------|------|
| **위홈이 KTO 하위 채널로 보임** | 별도 브랜드 "Hanokstay by Wehome" 유지. KTO 로고 동등 배치 |
| **KTO 자체 예약 채널과 경쟁** | KTO는 직접 예약을 처리하지 않음 (안내·인증만) → 충돌 없음 |
| **공공 협력 의사결정 속도** | 비협의 베타 우선 출시, 협력은 부가 가치 |
| **KTO 정책 변경 의존** | 협력은 비독점. 문체부·문화재청·지자체 병행 |

## 접근 순서 (단계별)

### 0단계 — 자체 출시 (Now ~ 6주)
- KTO 협의 없이 한옥스테이 베타 오픈
- 30~50 한옥 호스트 입점
- 영문 한옥 콘텐츠 라이브 (이미 작성됨)
- 인바운드 SEO 키워드 선점: "hanok stay", "stay in a hanok", "korean traditional house stay"

### 1단계 — 비공식 접촉 (6~8주)
- KTO 관광상품팀·국제관광본부 담당자에게 informal 미팅 요청
- 자료: "Hanokstay by Wehome 베타 결과 — 입점 OO곳, 예약 OO건, 외국인 비율 OO%"
- 톤: "협력하면 어떤 시너지가 가능한지 탐색하고 싶다" (요청이 아니라 제안)

### 2단계 — 공식 협력 제안 (8~16주)
가능한 협력 형태 (위홈에서 먼저 제안):

#### A. "Korea Hanokstay 공식 예약 채널" 지정
- VisitKorea의 한옥 페이지에서 "예약은 Hanokstay by Wehome으로" 링크
- 위홈은 한옥체험업 등록 100% 보장 데이터 제공

#### B. KTO 한옥스테이 인증 ↔ Wehome 인증 연계
- KTO Hanokstay 인증 한옥은 Wehome에서 자동 우선 노출
- Wehome 큐레이터 검수 통과 한옥은 KTO 인증 신청 시 패스트트랙

#### C. 공동 해외 마케팅
- KTO 14개 해외지사 통해 "Stay in a Hanok" 인바운드 캠페인
- 위홈은 영문/일문/중문 한옥 콘텐츠·예약 인프라 제공

#### D. 외국인 인바운드 데이터 공유 (양방향)
- 외국인 한옥 선호 패턴 (시즌·지역·체험) — KTO 정책 인풋
- KTO 인바운드 통계 — 위홈 마케팅 인풋

### 3단계 — 정책 협력 (16주~)
- 한옥체험업 제도 개선 협의 (위홈이 실데이터로 입증)
- K-LifeSharing 모델 정책화 자문
- 외국인관광 도시민박업 → 한옥 적용 확대

## 1차 미팅 어젠다 (KTO 요청 시 즉시 사용 가능)

**제목**: 위홈 한옥스테이 — 협력 가능성 탐색 미팅

**우리 입장**:
- 위홈은 한옥 카테고리에 풀(全)역량 투입 중
- 한옥체험업 100% 합법 운영 호스트만 입점
- 4개국어 AI 컨시어지로 외국인 인바운드 전환율 ↑
- 베타 OO주 만에 OO호스트, OO예약, 외국인 비율 OO%

**KTO에 묻고 싶은 것**:
1. KTO 한옥스테이 인증제와 Wehome 큐레이션이 어떻게 연계될 수 있나
2. VisitKorea의 한옥 카테고리에서 예약 채널이 필요한 시점인가
3. 해외지사 마케팅 캠페인에 한옥 콘텐츠 편입 가능성
4. 외국인 한옥 데이터 공유 가능 범위

**우리가 제공할 수 있는 것**:
- 외국인 한옥 예약·후기 익명화 데이터
- 영문/일문/중문 한옥 콘텐츠 라이브러리 (KTO 채널 자유 활용)
- 합법 운영 호스트 풀 (KTO 정책 사례 활용)
